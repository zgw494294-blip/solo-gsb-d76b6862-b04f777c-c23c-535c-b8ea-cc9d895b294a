⚙ 齿轮系转速求解台

录入轴、传动关系与已知转速，以有理数精确联立 — 外啮合 / 内啮合 / 行星轮系 · 目标配齿 · 理想传动转矩平衡 · 传动链路追踪 · 啮合谐波重合诊断 · 最少制动轴方案

① 轴 2～12 根，唯一整数编号

② 传动关系 1～24 条；齿数为 1～500 的整数

③ 已知转速 1～4 个；有符号整数或分数（rpm）

④ 目标转速配齿 选定一条关系的一个齿数与目标轴/转速，枚举 1～500 精确匹配

将该齿数字段依次替换为 1～500 的整数逐一精确求解；矛盾候选舍弃，整体欠定时只要目标轴转速不依赖自由变量且精确等于目标值即保留。

⑤ 理想传动转矩平衡 无损、无惯性：Aω = 0 的零空间中任意允许运动 v 均满足 τ·v = 0

已知外加转矩 1～12 项；有符号整数或分数（N·m）

待求转矩轴 1～12 根；不与已知转矩轴重复

同一轴不能同时已知和待求；未列出的轴外加转矩视为 0；已知转速不参与此计算。结果以有理数精确给出：无平衡解 / 唯一解 / 欠定（自由变量与各待求轴的精确仿射表达式）。

⑥ 传动链路追踪 每条关系是一步：外/内啮合连接 a/b，行星组连接 s/r/c；不使用转速或转矩

以经过的关系数为路径长度：返回最短链路总数、按每步（关系录入序号、到达轴录入序号）字典序最小的链路，以及所有最短链路必经的关系序号；并行关系分别计数，行星组不拆成三条啮合。起终点同轴时返回一条长度为零的空链路，不连通时返回零条。

⑦ 啮合谐波重合诊断 基频 f = z·|ω|/60 Hz（行星组取 |ωs−ωc|），1～12 次谐波按精确频率找跨关系重合

复用上方轴、传动关系与已知转速（校验与“求解”一致）：外/内啮合基频 f = za·|ωa|/60 Hz，行星组基频 f = zs·|ωs−ωc|/60 Hz，全部有理数精确计算。模型无解时返回原有冲突定位；欠定时基频仍依赖自由变量的关系标为“未确定”且不参与比较，其余关系给出精确基频。对每条确定且非零的基频取 1～12 次谐波，按精确频率分组，只列出包含至少两条不同关系的重合组（组内按关系录入序号、谐波次数排序）；参与重合的关系在录入区紫色高亮。任何输入变更即清空诊断结果。

⑧ 最少制动轴方案 只使用轴与传动关系：目标轴须恒不转动，保护轴必须仍可转动

可制动轴 勾选允许施加制动的轴；不得包含目标轴与保护轴

对每个候选制动集合，把所勾选轴的转速置零（ω = 0），与外/内啮合、行星组三类关系组成齐次有理数方程；仅当全部允许运动中目标轴转速恒为零、且存在保护轴转速非零的允许运动时集合有效。枚举可制动轴的全部子集（含空集），返回制动轴数最少的所有方案：方案内按轴录入顺序，方案间按该顺序的轴列表字典序排列；空集本身有效时返回含一个空集合的方案列表，无任何有效方案时明确说明。任何输入变更即清空方案结果。
